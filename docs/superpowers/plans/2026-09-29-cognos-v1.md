# COGNOS v1.0 Implementation Plan

> **For agentic workers:** executed natively (inline) by the session that wrote it; owner delegated
> plan/spec approvals and asked for the finished product. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Turn COGNOS into an agent-recommends / human-decides / engine-disposes system with a
DAG workflow engine, a real agent layer (5 providers), human gates, challenges, gaps, audit, and a
Dash + Mantine UI — released as v1.0.

**Architecture:** New `engine/` (graph, state, gates, events) and `agents/` (contracts, prompts,
slices, heuristic, runner, backends) packages; stages call `ctx.recommend()` between engine
`prepare` and `finalize`; `service.py` is the single boundary used by CLI and `ui/`.

**Tech Stack:** Python ≥3.11, pydantic v2, numpy/pandas/sklearn/statsmodels (unchanged core),
anthropic SDK, openai SDK, `claude` CLI 2.1.x, Dash 4 + dash-mantine-components 2.x + dash-iconify, plotly.

**Spec:** `docs/superpowers/specs/2026-09-29-cognos-v1-design.md`

## Global Constraints

- Tests + lint: `pytest` green and `ruff check src/ tests/` clean before every commit.
- Offline: every test runs with provider `heuristic` (autouse fixture sets `COGNOS_PROVIDER=heuristic`); no network, no key.
- Frozen substrate: `data/holdout.parquet` and `modeling/metrics.py` never agent-editable; modeler never sees holdout metrics.
- BLOCK only from `validate` (confirmed leakage) and `review` (stale code refs); agents cannot BLOCK; accept is disabled on BLOCK.
- Heavy artifacts by reference; `StageResult.payload` small.
- All file I/O `encoding="utf-8"` (Windows).
- Default Anthropic model `claude-sonnet-5-5`; `claude_cli` model alias `sonnet`.

## Review Focus

1. Double-submitting a gate (double click / two tabs) → second submit rejected with "gate is not awaiting a decision", state unchanged. → Task 3 test.
2. Send-back or gate edit while a downstream step is running → that step finishes as `stale` and re-runs, never `done` with stale inputs. → Task 3 test.
3. An agent cites an unknown fact id / invalid champion on every attempt → step `failed` with the validation errors visible; `retry` re-runs it. → Task 5 test.
4. Choosing a provider that is unavailable (no key / no CLI) → `create_run` raises a clear error naming the available providers; `auto` silently falls back to heuristic. → Task 5 test.
5. Opening a legacy v0.5 run directory (no `state.json`) in `list_runs`/UI → listed as `legacy`, read-only, no crash. → Task 8 test.

## Phase 1 — Engine core (deterministic agents only)

### Task 1: Graph + state
- Files: `engine/graph.py`, `engine/state.py`, `engine/events.py`; test `tests/unit/test_engine_state.py`.
- Produces: `STEPS: list[str]`, `DEPS: dict[str, list[str]]`, `GATES: list[str]`, `descendants(step)->list[str]`; `RunState.load(run_dir)->RunState`, `RunState.save(run_dir)`, `run_lock(run_dir)->RLock`, `RunState.set_step(name, status, message=None)`, `RunState.invalidate(steps)->list[str]`.
- [ ] Tests: descendants of `gate_data` = everything after it; invalidate marks only done/awaiting/failed/running/blocked; skipped satisfies deps; state round-trips JSON; events append + history(since).
- [ ] Implement, run, commit with Task 2–3.

### Task 2: Context + config for v1
- Files: `config.py` (AgentsConfig{provider='auto', model, max_retries=2, time_limit_s=300, budget_usd=5.0, replay_dir}, WorkflowConfig{gates=[5 gates], auto_challenge_loops=2}; migrate `brain:`), `context.py` (effective config from overrides; `features()`; `recommend()`; `challenges_for(stage)`; remove brain).
- [ ] Tests: overrides.exclude_columns flow into `data.drop_columns` and `features()`; design answers fill `design`; legacy `brain: {kind: llm}` maps to `agents.provider: anthropic`.

### Task 3: Engine + gates
- Files: `engine/engine.py`, `engine/gates.py`; test `tests/unit/test_engine.py`, `tests/integration/test_workflow.py`.
- Produces: `Engine(config, run_id=None, runs_root=None, provider=None)`, `.run_until_idle()->RunState`, `.advance()` (background), `.wait(timeout)`, `.submit_gate(gate, action, payload=None, reason='')`, `.answer_gap(gap_id, answer, action='answer')`, `.retry(step)`, `.state`.
- Gate actions: `accept | edit | override | send_back | approve | reject`.
- [ ] Tests: autonomous heuristic run completes all 13 steps with auto decisions; interactive run pauses at `gate_data`; accept advances; double submit rejected (Review Focus 1); edit after downstream done → descendants stale & rerun; send_back creates Challenge and the stage agent's response is recorded; step marked stale while running stays stale (Review Focus 2, simulated via hook); leakage config BLOCKs, accept on BLOCK rejected, send_back to explore with exclusion → run completes PASS; gap answer re-enters ideate; `Orchestrator`/`run_pipeline` compat still return summaries.

The problemCOGNOS
Where we started

A language model can build a credit model in an afternoon. Nobody could sign it.

01

The numbers cannot be reproduced.A model that writes its own figures can write a different figure tomorrow.

02

The judgment cannot be traced.Why this target, this segment, this champion? The reasoning is gone when the chat closes.

03

The challenge is not independent.The same agent that built the model is asked whether it is any good.

04

Nobody is accountable.A decision that no person made is a decision no person can defend.

Model risk guidance (SR 26-2, which replaced SR 11-7 in April 2026) asks for the opposite of all four: reproducible results, documented choices, effective challenge and named owners.

COGNOS keeps the speed of agents and removes those four failures by construction, not by asking the agents to behave.

The ideaCOGNOS
One sentence holds the whole design

Three kinds of work, and each one goes to whoever can be trusted with it.

The engine
disposes

Mechanics: plain code that sequences, computes every number, guards the holdout, applies decisions and keeps the record.

  • deterministic
  • no judgment, no "smart supervisor"
  • runs with no network at all
Agents
recommend

Judgment: reading a business intent, naming a target, ranking designs, picking a champion, challenging a model, writing prose.

  • no tools of their own
  • cite facts, never type numbers
  • every answer checked before it counts
People
decide

Accountability: a named person in a named seat accepts, changes, sends back or rejects at every gate.

  • model developer
  • independent reviewer
  • approver

    Principle 1 of 8COGNOS
    01 / 08
    No LLM math

    An agent never writes a number. It points at one.

    Every recorded figure comes from the engine. The writer leaves a placeholder; the engine fills it from the fact it names. An unknown fact id, or a bare metric typed into prose, is rejected.

    Principle 2 of 8COGNOS
    02 / 08
    The frozen substrate stays frozen

    The champion is chosen before the holdout opens. Every look is counted.

    The holdout and the metric definitions are not editable by any agent. Candidates are compared on a test sample, and each look at it is counted. The sealed holdout is scored once, after the choice, and no agent that chooses sees a holdout fact. Exports never carry the data.

    Principle 3 of 8COGNOS
    03 / 08
    Independent challenge

    The validator is never told why the modeler liked the model.

    Validation, readiness and review re-derive risk from the artifacts themselves. Independence is a property of what each agent is handed, so it does not depend on an instruction being obeyed.

    Two agents, two views of the same run

    Modeler sees

    • the leading candidates
    • development and validation scores
    • coefficient signs
    • test or holdout results
    • the earlier model's scores

    Validator sees

    • the champion and its features
    • the engine's rubric and findings
    • test and holdout results
    • every analysis script, re-run
    • the modeler's rationale
    Principle 4 of 8COGNOS
    04 / 08
    Block only on high-confidence harm

    A system that blocks on noise teaches people to ignore it.

    Only the engine can block, and only on two things it can prove. An agent can warn or fail, never block. A person can accept a fail with a recorded reason. Nobody can accept a block.

    The verdict ladder
    Pass

    Nothing to raise.

    Warn

    Something a reviewer should read: a noisy overfitting signal, an unconfirmed assumption, a recorded limitation.

    Fail

    A high-severity finding. A person may accept it, in writing, or send the work back.

    Block

    Confirmed target leakage, or documents that no longer match the code. Fix it or reject the run.

    Principle 5 of 8COGNOS
    05 / 08
    Nothing is silently assumed

    What the sponsor has not decided is a question on the record, not a guess in the model.

    Agents raise questions for the business sponsor at the stage where they arise. Each one closes in one of three ways, and each way has a consequence.

    Three ways to close a question

    Four can only be answered: use, horizon, default definition and segment.

    Principle 6 of 8COGNOS
    06 / 08
    Agents ask, the engine runs

    An agent cannot execute anything. Even its own code is an artifact someone reads.

    An agent asks for an analysis by naming a reviewed tool, or by writing a short script. The engine runs it, in a restricted process, and keeps the result. Every chart says which of the three it came from.

    Where an analysis comes from
    Built-in

    Reviewed COGNOS code: 14 exploration tools, from a data overview to weight of evidence and drift.

    Plugin

    Reviewed code a team adds. A plugin brings tools and data sources, never prompt text.

    Script

    Written by the agent for this run. It follows a chain:

    checked→saved with hash→run restricted→read at the gate→re-run at validation→printed in the paper
    Principle 7 of 8COGNOS
    07 / 08
    A change always says why

    Change your mind at any gate. The run works out what is now out of date, and why.

    A person's decision never edits the project profile. It is stored as an override, everything downstream is marked stale with the reason, and the engine re-runs it. The previous result is kept so the two can be compared.

    Principles 2 and 7, togetherCOGNOS
    Trial runs

    Try a decision another way. Lose nothing, hide nothing.

    A developer copies a run at any of their gates and decides it differently. The first result stays as it was, and the two are compared side by side. What would make this dangerous is a quiet best-of-many, so every run of a model is on one record that validation reads.

    Three rules for a trial run
    Stops

    It ends once a champion is chosen. Only the main run goes to validation, so a trial run can never open the sealed holdout.

    Counted

    Every look at the test sample is added up for the model, across all of its runs. Validation and the white paper report the total.

    Kept

    Deleting a trial run removes its files. Its line stays: what it tried, how far it went, what it found.

    Main

    To carry a trial run forward, the developer makes it the main run. The run it replaces stays on record.

    Principle 8 of 8COGNOS
    08 / 08
    Always runnable with no model at all

    Take the language model away and the system still runs end to end.

    A missing key or network makes a provider unavailable. It never makes a run crash. That is what makes the system testable, and why the language model is an accelerator here, not a dependency.

    The outputCOGNOS
    The model is half of the deliverable

    A run ends with a model and with the file a validator would otherwise have to ask for.

    01

    The white paper.Methodology, model card, limitations and assumptions, every number rendered from a recorded fact.

    02

    The run record.Who did what and when: each recommendation, decision, question and challenge, with names.

    03

    The agent calls.The full input and raw output of every attempt by every agent.

    04

    The analysis code.Every script an agent wrote, with its hash, as it was run.

    05

    The readiness report.Evidence organised against model-risk expectations, with the human-only steps listed.

    06

    The sealed package.Written once at sign-off. A later change supersedes it and never rewrites it.

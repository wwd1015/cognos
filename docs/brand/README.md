# The COGNOS logo

| File | Use |
|---|---|
| `cognos-logo.svg`, `cognos-logo-dark.svg` | The wordmark, on light and dark grounds |
| `cognos-mark.svg` | The mark alone: the tab icon (`src/cognos/ui/assets/favicon.svg`) and the deck's icon |
| `cognos-seal.svg` | The stamp a person's decision carries at a gate (`src/cognos/ui/assets/seal.svg`) |

The wordmark's two O's carry the creed. The first is dashed: the agents suggest. The second is
solid oxblood: a person decides. The seal puts the creed on its rim.

This is a first pass, drawn by hand in the Ledger palette (ink `#16140f`, oxblood `#7d2230`;
on dark, `#f0ede4` and `#e0939e`). The letters are set in Source Serif 4 with system serif
fallbacks rather than outlined, so they can still be refined.
